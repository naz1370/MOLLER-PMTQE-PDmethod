
Interactive visualization of photocathode sensitivity measurements for 43 PMT
entries characterized for the MOLLER experiment at Jefferson Lab using photodiode at 280V and 400nm.

## Usage

Open `.html` in any browser. No installation or internet connection required.

## Features

- **Y-axis selector** — plot I_LED, I(nA), S(C), S(C)/e, or PPD(nW) against photocurrent I(nA)
- **PMT checklist** — all series shown by default; uncheck any to hide it
- **Bulk filters** — Select All / Deselect All / Only R2 / Hide R2 / Invert
- **Search** — filter the checklist by serial number
- **Hover tooltips** — exact values for any data point
- Reference line at S(C)/e ≈ 0.24

## Data notes

- Serials tagged **R2** are second-round measurements and are plotted as separate
  series (dashed lines), not merged with the first round.
